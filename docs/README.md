# ProjeCRM dokümantasyonu

Bu dizin, projenin teknik geçmişini ve GitHub vitrininde kullanılan sentetik arayüz görsellerini bir arada tutar.

## İçerik

- [`screenshots/`](screenshots/): İzole yerel veritabanındaki örnek kayıtlarla oluşturulan ürün ekranları
- [`refactor-raporu.md`](refactor-raporu.md): Frontend bileşenlerinin modülerleştirilme ve optimizasyon geçmişi

## Ekran verisi politikası

Dokümantasyon görsellerinde canlı sistem verisi kullanılmaz. Tüm adlar, telefon numaraları, adresler, kullanıcı hesapları, ücretler ve operasyon kayıtları yalnızca ekran gösterimi için üretilmiş sentetik verilerdir.
